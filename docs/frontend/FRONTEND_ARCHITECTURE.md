# Purpose

The frontend is the operational control layer for Karpathys.

It is NOT:
- a marketing website
- a consumer social app
- a chatbot shell
- a generic CRM

It IS:
- a realtime operational dashboard
- a workflow command center
- an AI governance interface
- a transcript intelligence system
- a deterministic control surface

The frontend exists to:
- visualize operational truth
- coordinate workflows
- surface AI assistance
- manage approvals
- inspect events
- monitor system state
- control realtime execution

---

# Frontend Philosophy

The frontend is:
- operator-first
- information-dense
- low-friction
- keyboard-driven
- realtime-aware
- audit-friendly
- deterministic
- accessibility-first

The UI must feel:
- stable
- operational
- trustworthy
- explainable
- traceable
- responsive

NOT:
- playful
- noisy
- over-animated
- consumer-social
- AI-hype driven
