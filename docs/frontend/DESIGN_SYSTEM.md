# Purpose

The Karpathys design system defines the visual operating language for:
- workflows
- approvals
- transcripts
- realtime systems
- operational intelligence
- AI-assisted execution

This is NOT a marketing design system.

This is an operational systems interface.

The design language must prioritize:
- clarity
- density
- scanability
- consistency
- speed
- trust
- explainability

---

# Visual Philosophy

Karpathys should feel:

- operational
- stable
- intelligent
- modern
- high-trust
- deterministic
- calm under load

NOT:
- playful
- trendy
- over-animated
- social-media styled
- “AI magic”
- startup gimmicky

---

# Design Priorities

Priority order:

1. readability
2. information hierarchy
3. operational speed
4. accessibility
5. responsiveness
6. visual consistency
7. motion polish
8. aesthetic expression

Function overrides decoration.
